Ganso Morpho

Biblioteca de animações do mascote. Animação programática em canvas, sem dependências: um arquivo, uma tag.

Como usar

Três jeitos, do mais prático ao mais solto. A pasta mascote/ é tudo o que precisa ir junto.

1. Com a tag

Inclua o arquivo uma vez e use a tag onde quiser. Trocar o atributo troca a animação.

<script src="mascote/ganso.js"></script>

<morpho-ganso anim="pensativo"
  style="width:200px"></morpho-ganso>

<script>
  const g = document.querySelector('morpho-ganso');
  g.anim = 'gritando';   // troca
  g.reiniciar();         // volta ao início
</script>

2. Por código

Cada animação é uma função do tempo. Ganso.desenhar() pinta o quadro de qualquer instante num canvas seu.

const ctx = tela.getContext('2d');
Ganso.desenhar(ctx, 'matrix', segundos,
  { tamanho: 512, pb: false });

Ganso.nomes      // ['parado', 'dormindo', …]
Ganso.animacoes  // título, descrição e ciclo
g.tempo = 1.5;   // na tag: pula para 1,5 s

3. Como imagem ou vídeo

Onde não dá para rodar JavaScript, use os botões do palco, lá em cima: eles exportam a animação escolhida.

Atributos e cores

Atributos da tag e variáveis CSS que trocam as cores, postas na própria tag ou em qualquer elemento em volta.

animNome da animação. Vazio mostra o ganso parado, sem movimento.
velocidadeMultiplicador. 2 dobra a velocidade, 0.5 deixa em câmera lenta.
pausadoCongela no quadro atual.
pbSó preto e branco: sem o vermelho da boca, o azul das lágrimas e as outras cores.
contornoPõe um contorno branco em volta, para fundos escuros ou coloridos.
rotuloTexto para leitores de tela.
--ganso-tintaPreto do desenho.
--ganso-papelBranco do bico e dos brilhos.
--ganso-boca, --ganso-linguaDentro do bico.
--ganso-acentoVermelho do rosto bravo.
--ganso-lagrima, --ganso-babaLágrimas, suor e baba.
--ganso-codigoChuva de código nas lentes.
